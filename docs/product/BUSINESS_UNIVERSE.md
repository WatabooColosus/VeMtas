# Universo Negocio

## Ciclo de alta

DRAFT → PENDING_VERIFICATION → UNDER_REVIEW → VERIFIED → ACTIVE.

También:

- SUSPENDED
- REJECTED

## Jerarquía

Negocio
→ sucursal
→ caja
→ terminal
→ empleado/sesión.

## Capacidades

- información comercial;
- ubicación;
- horarios;
- catálogo;
- productos/servicios;
- precios;
- inventario;
- empleados;
- roles;
- terminales;
- ventas;
- promociones;
- fidelización;
- rutas;
- calificaciones;
- analítica;
- finanzas operativas.

## Escala

La misma arquitectura debe representar una tienda individual, una cadena y establecimientos dentro de un centro comercial.

## Visibilidad

Todo comercio afiliado puede disponer de presencia orgánica básica.

La publicidad patrocinada debe estar claramente diferenciada.
