# Security Policy

VeMtas se encuentra en desarrollo temprano.

No publicar en este repositorio:

- llaves API;
- secretos;
- tokens;
- credenciales bancarias;
- PII real;
- credenciales productivas;
- datos financieros reales.

Las vulnerabilidades encontradas durante desarrollo deben tratarse como bloqueantes cuando puedan comprometer dinero, identidad, ledger, permisos o auditoría.
